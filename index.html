Maturitní projekt

Model chytrého zabezpečení domácnosti (IoT) — popis „case study“

Model chytrého zabezpečení domácnosti (Arduino + Wi-Fi)

Funkční model: detekce pohybu (PIR), detekce CO (MQ-7), akustický alarm, autorizace přes klávesnici, zámek simulovaný servem a notifikace do Telegramu přes Wi-Fi (relay architektura).

Arduino Mega 2560 ESP8266 (AT) PIR MQ-7 (CO) LCD 16×2 (I²C) Keypad Servo lock
Technické poznámky (rozbalit)
  • Stavový model (režimy: deaktivováno / odchodové zpoždění / aktivní / lock-only).
  • MQ-7 vyhodnocení: baseline kalibrace, práh + hystereze, cooldown po poplachu.
  • Notifikace: ESP8266 → HTTP (bez TLS) → relay server → Telegram (HTTPS).
  • Offline-first: lokální alarm funguje i při výpadku Wi-Fi; události lze frontovat.

(Detailní stránku projektu doplníme jako další krok: schéma, fotografie, testovací scénáře, odkazy na dokumentaci.)

Nejde jen o „zapojení“. Je to propojení hardwaru, logiky, UI a sítě do stabilního chování.
